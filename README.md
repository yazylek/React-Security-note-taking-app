# 📝 Notees – Notes App

**Notees** is a secure note-taking web application with authentication via **email** and **GitHub login**. Built with **React** and **Tailwind CSS** on the frontend, and **Java Spring Boot** on the backend (currently offline). This app was developed to practice **authentication**, **frontend/backend integration**, and **animations with Framer Motion**.

🔗 [Live demo](https://notees-fawn.vercel.app/)

---

## 🚧 Project Status

🔹 Developed as a full-stack learning project  
🔹 Currently includes:
- Login & register flow (with email and GitHub)
- Light & dark theme support
- Notes dashboard and note editor
- Framer Motion animations for smooth transitions

❗ Backend is currently offline. Note saving and fetching do not work without running the backend locally.

---

## 🎯 Key Features

- **User authentication** (email + GitHub via OAuth)
- **Light/dark theme toggle**
- **Framer Motion animations**
- **Note creation and editing UI**
- Built using component-based architecture in React
